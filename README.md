# iClaustron

A client library for RonDB 26.10 data nodes (the NDB API) written in
C-like Rust, MIT licensed, usable from Rust, C, C++ and any language that
can call C.

Status: Phase 0 (bootstrap). Nothing works yet. The plan and design live in
[`doc/rust/`](doc/rust/README.md); start with the index there.

Phase 0 checklist (see `doc/rust/06-phases.md`):

- [x] C code moved unchanged to `legacy-c/`, root `LICENSE` is MIT
- [x] Cargo workspace with the eight empty crates and `xtask`
- [x] `rust-toolchain.toml`, `rustfmt.toml`, `clippy.toml`, `deny.toml`
- [x] `include/iclaustron/ic_apid.h` rewritten to chapter 04 (design review artefact)
- [x] `doc/dev-cluster.md`
- [x] `cargo xtask tags` for vim/gvim navigation over Rust and C (replaces `git_tags.sh`)
- [x] Rust toolchain installed, `cargo build --workspace` and `cargo xtask check` pass
- [ ] Header reviewed (developer)
- [ ] RonDB 26.10 development cluster running (developer)

## Layout

```
crates/            the library, one crate per module (see doc/rust/03-module-map.md)
include/           the C header (design artefact now, generated by cbindgen later)
xtask/             developer commands: cargo xtask check | style | header | test-integration | tags
doc/rust/          the plan
doc/dev-cluster.md how to run a RonDB 26.10 cluster for development
legacy-c/          the original iClaustron C code, unchanged, unbuilt, for reference
```

## Building

Requires a stable Rust toolchain (`rustup`, see `doc/rust/08-testing-and-tooling.md`).

```
cargo build --workspace
cargo test --workspace
cargo xtask check
```
