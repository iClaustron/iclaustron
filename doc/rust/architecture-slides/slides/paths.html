On the send side, the request is built once, at define time, where the data already is; send only patches flags. On the receive side a page is allocated and freed only on the thread that owns it. A large TRANSID_AI is never copied: the user thread reads it inside the receive page, which stays sealed until the page is given back. Commit acknowledgements ride along with the next send.
