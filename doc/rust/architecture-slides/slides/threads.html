03

Walk the orange path. A user thread packs its requests, appends them to the node's send buffer and, if no one else is writing to that node, writes the socket itself: one write per node. The send pool only writes what came in during someone else's write, and what adaptive send held back. Replies come in on the receive thread that owns that node, which sorts them per user thread and posts one page per thread per round. Heartbeat and connect threads never touch transaction signals.
